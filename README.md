# 宠物电商后端

## 项目介绍
本项目为一个宠物电商系统，集成了多角色登录、商品浏览、交易支付（模拟支付）与后台管理四大核心模块。系统支持用户通过账号或手机号（模拟验证码发送）登录，并提供了从首页浏览、商品搜索、购物车管理到下单支付的全流程购物操作。同时，拥有后台管理端，允许宠物店管理自身商品与订单，平台管理员管理系统信息，例如平台展示内容、角色管理等。

宠物电商前端===> [cd-water/pet-mall-vue](https://github.com/cd-water/pet-mall-vue)

**后端技术栈：**

* Spring Boot
* MySQL
* MyBatis
* Redis
* 阿里云OSS
* JWT令牌技术
* WebSocket
