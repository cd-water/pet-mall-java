# 宠物电商后端

## 项目介绍
本项目为一个宠物电商系统，集成了多角色认证与权限管理模块、商品浏览与购物管理模块、交易支付与订单管理模块、后台运营管理模块。支持游客、普通用户、宠物店主、管理员四类角色差异化操作，提供账号 / 手机号登录（模拟验证码发送）、注册、密码找回及 “记住我” 功能，普通用户可进行商品分类浏览、首页推荐查看、购物车与收藏夹管理、地址管理、下单支付（模拟支付）及订单查询等操作，宠物店主可通过后台管理店铺商品、处理订单并查看营业数据，管理员负责平台内容配置、公告发布、入驻审核及系统角色管控。

宠物电商前端===> [cd-water/pet-mall-vue](https://github.com/cd-water/pet-mall-vue)

**后端技术栈：**

* Spring Boot
* MySQL
* MyBatis
* Redis
* 阿里云OSS
* JWT令牌技术
* WebSocket
